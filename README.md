## About

Software Engineer at [OmniChat](https://omni.chat), Latin America's largest conversational-commerce SaaS. I own the billing, plans and contracts platform: 8+ Node.js/TypeScript microservices on AWS Lambda, SQS and EventBridge.

- Rewrote the billing platform from scratch (idempotent, parallel, reconciled, observable) and switched it over with zero downtime. Duplicate charges and failed invoices stopped.
- Test strategy for money-path code: golden-master E2E, 100% branch and mutation coverage with Stryker, CI gates.
- Daily driver is an agentic setup I built on Claude Code (custom skills, plugins, MCP servers, parallel workers), with Codex, Pi and Hermes as alternate agents.
- Before this: product manager and full-stack developer at a software house (React Native, Node, C#/.NET, Azure).
- Studying: Master's in Artificial Intelligence (AGTU, USA) and Full Cycle 4.0. High school and two years of university in Georgia, USA.
